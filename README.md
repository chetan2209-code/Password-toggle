## Password Toggle ##
A simple and responsive Password Toggle project built using HTML, CSS, and JavaScript. This project allows users to show or hide their password by clicking an eye icon, improving usability while maintaining a clean interface.

**UI updated with modern CSS**

# BUILT WITH #
- HTML5
- CSS3
- JavaScript

**LIVE LINK:** https://chetan2209-code.github.io/Password-toggle/

✨ Features
- 👁️ Show/Hide password with a single click
- 🔒 Toggle between hidden and visible password
- 📱 Responsive design
- ⚡ Instant UI update without page reload
- 🎯 Beginner-friendly JavaScript project

  # How It Works

  1. Enter a password in the input field.
  2. Click the eye icon.
  3. The password switches between:
     - Hidden (password)
     - Visible (text)
  4. Click again to hide it.
